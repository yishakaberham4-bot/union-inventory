Put these files in your Next.js project **public/** folder (project root):

  public/manifest.webmanifest
  public/sw.js
  public/icons/icon-16.png
  public/icons/icon-32.png
  public/icons/icon-180.png
  public/icons/icon-192.png
  public/icons/icon-512.png
  public/apple-touch-icon.png
  public/logo.png

The app/ folder content goes to your app/ directory as usual.

Android install:
1. Deploy site with HTTPS (required for PWA)
2. Open Chrome on Android → site URL
3. Menu → "Install app" / "Add to Home screen"
   OR wait for the in-app Install banner
4. App opens full screen with UNION icon

Language: choose አማርኛ on home page — labels switch to Amharic and stay saved.
